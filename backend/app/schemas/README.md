# Schemas

Pydantic v2 request/response şemaları.

## Şemalar

- `auth.py` — LoginRequest, TokenResponse, UserCreate
- `job.py` — JobCreate, JobUpdate, JobResponse
- `cv.py` — CVUpload, CVResponse
- `application.py` — ApplicationCreate, ApplicationResponse
- `agents.py` — Analyze, CoverLetter, MockInterview start/answer/session schemas
- `calendar.py` — Calendar event schemas
